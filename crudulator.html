Using CRUDulator

    
  

  

    
CRUDulator turns a SQLite table into a simple data-entry application: list, search, add, edit and delete records. It opens with a sample contacts table so you can try it.


    
Designing a table

    
    
      
  • Click New table, give it a name, and add columns. Each column has a type and can be marked Required.
    • 
      
  • Types: Text, Long text (a multi-line box), Whole number, Decimal number, Date, Yes / No, and Link to another table.
    • 
      
  • An id column is added for you and numbered automatically.
    • 
      
  • The SQL that will run is shown before you save it.
    • 
      
  • Edit table design lets you rename a table, add columns, remove columns or delete the whole table.
    • 
    


    
Linking tables

    
    
      
  • A column can link to a record in another table (a foreign key). For a new column, choose Link to table as its type.
    • 
      
  • To turn an existing column into a link, open Edit table design and choose Change to link → table in that column's type box. A text column is matched against the other table's first text column, for example issuer names against Issuers.Name; a number column is matched against its id. If any values have no match, you're told which, and nothing changes.
    • 
      
  • In the list, a linked column shows the linked record's name; in the form it's a drop-down.
    • 
      
  • Links are enforced: you can't delete a record while others still link to it.
    • 
    


    
Working with records

    
    
      
  • Click New record to add one, or click any row to edit or delete it.
    • 
      
  • Type in the search box to show only rows where any column contains that text.
    • 
      
  • Click a column heading to sort by it; click again to reverse the order.
    • 
      
  • The list shows up to 500 rows at a time. Search to narrow it down.
    • 
    


    
Opening and saving

    
Everything happens in your browser; nothing is uploaded. Open database… (or dropping a file onto the page) loads an existing SQLite file, and you can work with any of its tables. Download database saves a copy as a file.

    
New database asks for a file name. To change the name of any database, click its name under the title; the new name is used the next time you download. If you leave out the extension, .db is added.


    
Saved in this browser

    
Every change is saved automatically in this browser's own storage, and the database reopens when you come back to the page. The header shows saved in this browser when that has worked.

    
The browser keeps one database at a time. Opening a file or starting a new database replaces it, so you'll be asked first if the current one has changes you haven't downloaded.

    
This copy belongs to this browser on this computer only, and clearing your browsing data deletes it. Treat Download database as your real backup: the Not downloaded tag shows when there are changes that aren't in a downloaded file yet.

    
When the page is opened inside Claude, the database is saved inside a .zip file, because Claude doesn't allow .db downloads directly.


    
Requirements

    
The page loads sql.js and JSZip from cdnjs, so it needs an internet connection when it first opens.
