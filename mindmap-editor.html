Links and connectors

Type a web address in the Link box to attach it to the selected node; clear the box to remove it. If you leave out https://, it is added for you.

A connector is a dashed arrow from one node to any other, with an optional label. Select the first node, choose Connect, then click the second node and type a label if you want one. Deleting a node also deletes its connectors. When a branch is folded, its connectors go to the folded node.

Notes

Select a node and type in the Note panel. Nodes with a note show a small page icon. Press Esc to leave the note and go back to the map.

Notes use Markdown: **bold**, *italic*, - or 1. for lists, # for a heading, `code` and [text](https://…) for a link. When you leave the note it is shown formatted; click or tap it to edit it again. Links in a note open in a new tab.

Images

A node can have one PNG or JPEG image, shown under its title. Select the node and choose Attach image… from the Image menu; on a phone or tablet this offers your photos and camera. You can also drop an image file onto a node, or paste one to put it on the selected node. Attaching another image replaces the first; Remove image takes it off. Both can be undone.

Large photos are shrunk to 1600 pixels on their longer side when attached. On the map, images are scaled to fit within 200 × 200 pixels.

Images are saved in the .zip file, in an images folder beside the YAML file, and are kept in this browser between visits. A plain .yaml file can't hold images, so a node whose image isn't in the file shows Image missing.

Maths in notes

Write formulas in LaTeX. Put $…$ round a formula within a line, and $$…$$ round one that should stand on its own. Type \$ for a dollar sign that isn't maths; a price such as $5 is usually left alone anyway.

x^2 x^{10}
Superscript. Use braces for more than one character.
a_1 a_{ij}
Subscript.
\frac{a}{b}
Fraction.
\sqrt{x} \sqrt[3]{x}
Square root, cube root.
\alpha \beta \pi \Omega
Greek letters; a capital first letter gives a capital.
\sum_{i=1}^{n} \int_0^1
Sum and integral, with limits.
\le \ge \ne \approx
≤ ≥ ≠ ≈
\times \cdot \pm \infty
× · ± ∞
\to \Rightarrow \in \subset
→ ⇒ ∈ ⊂
\left( \frac{a}{b} \right)
Brackets that grow to fit.
\text{if } x > 0
Ordinary words inside a formula.

For more, see Overleaf's Mathematical expressions guide. It is written for whole LaTeX documents, so skip the parts about packages and numbered equations; the symbols and examples work in notes. A formula with a mistake is shown in red.

Saving

Save (in the File menu) downloads the map as a .zip file holding one YAML file. Open reads one of those, or a plain .yaml file, and replaces the current map; you can also drop a file onto the map. Undo brings back the map you replaced, until you reload the page.

Export as Markdown (also in the File menu) downloads the map as a .zip file of linked Markdown pages, one per branch, in folders arranged like the map, with the images. Each page has the branch's icons, title, picture, web link and note, then links to the branches under it and to its connectors' targets, and at the bottom to the previous and next branch and back up to its parent. Notes and maths are copied as they are, so they show on GitHub or in Obsidian. The editor can't open an export again: use Save for that.

The YAML does not record which side of the centre a branch is on, so an opened map shares its branches between left and right.

Open from server and Save to server appear in the File menu when the editor comes from a mind map server on your own network. The server keeps maps in one folder, so all your devices share them. If a map has changed on another device since you opened it here, Save to server asks before replacing it.

Maps on the server can be kept in folders. Open from server and Save to server show one folder at a time: choose a folder to look inside it, and use the path at the top to go back up. In both, each map has Move…, to rename it or put it in another folder, and Delete, which moves it to a .trash folder on the server. Saving a new map asks for its name and folder; New folder… makes one, which is kept once a map is in it.

A map on the server has its own address, which the address bar shows while it is open, such as …:8765/?map=garden; use it to link to the map from notes. While a map from the server is open, Ctrl+S saves it back to the server under the same name, and the browser asks before you close the tab with changes not yet saved there.

The current map is also kept in this browser between visits, but not on other browsers or devices, so use Save to keep a copy.
