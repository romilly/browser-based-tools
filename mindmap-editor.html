Mind Map Editor

How to use the editor

Mouse and touch

Click or tap
Select a node.
Double-click or tap
Edit the node's title.
Numbered circle
Shows a folded branch and how many nodes it hides. Click it to unfold.
Drag empty space
Move around the map. On a phone, swipe.
Hover a node
Shows its note, if it has one.

Keyboard

Tab or Insert
Add a child to the selected node.
Enter
Add a sibling below the selected node. On the root, adds a child.
F2
Edit the selected title.
Delete
Delete the selected node and everything below it.
Space
Fold or unfold the selected branch.
← →
Move towards or away from the root.
↑ ↓
Move between siblings.
Ctrl+Z
Undo. Ctrl+Y redoes.
?
Open this help.

While editing a title

Enter
Save the title.
Shift+Enter
Start a new line in the title.
Tab
Save and add a child.
Esc
Cancel the change.

Notes

Select a node and type in the Note panel. Nodes with a note show a small page icon. Press Esc to leave the note and go back to the map.

Saving

The map saves automatically in this browser. It is not shared with other browsers or devices. New map replaces the current map; Undo brings it back until you reload the page.
