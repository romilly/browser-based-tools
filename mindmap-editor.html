Mind Map Editor

How to use the editor

Menus and toolbar

File
New map, Open and Save.
Icons
Choose an icon to add it to the selected node, before its title. Choose it again to take it off. Remove all icons clears the node's icons.
Toolbar
Buttons for the editing commands that also have keys, for use on a phone or tablet.

Mouse and touch

Click or tap
Select a node.
Double-click or tap
Edit the node's title.
Numbered circle
Shows a folded branch and how many nodes it hides. Click it to unfold.
Drag empty space
Move around the map. On a phone, swipe.
Hover a node
Shows its note, if it has one.
Link icon
Opens the node's web link in a new tab.
Click a connector
Select it to change its label or delete it.

Keyboard

Tab or Insert
Add a child to the selected node.
Enter
Add a sibling below the selected node. On the root, adds a child.
F2
Edit the selected title.
Delete
Delete the selected node and everything below it.
Space
Fold or unfold the selected branch.
C
Connect the selected node to another: then click the other node. Esc cancels.
Ctrl+K
Type a web link for the selected node.
← →
Move towards or away from the root.
↑ ↓
Move between siblings.
Ctrl+↑ ↓
Move the selected branch up or down among its siblings. The Up and Down buttons do the same.
Ctrl+Z
Undo. Ctrl+Y redoes.
Ctrl+S
Save the map. Ctrl+O opens one.
?
Open this help.

While editing a title

Enter
Save the title.
Shift+Enter
Start a new line in the title.
Tab
Save and add a child.
Esc
Cancel the change.

Links and connectors

Type a web address in the Link box to attach it to the selected node; clear the box to remove it. If you leave out https://, it is added for you.

A connector is a dashed arrow from one node to any other, with an optional label. Select the first node, choose Connect, then click the second node and type a label if you want one. Deleting a node also deletes its connectors. When a branch is folded, its connectors go to the folded node.

Notes

Select a node and type in the Note panel. Nodes with a note show a small page icon. Press Esc to leave the note and go back to the map.

Notes use Markdown: **bold**, *italic*, - or 1. for lists, # for a heading, `code` and [text](https://…) for a link. When you leave the note it is shown formatted; click or tap it to edit it again. Links in a note open in a new tab.

Saving

Save (in the File menu) downloads the map as a .zip file holding one YAML file. Open reads one of those, or a plain .yaml file, and replaces the current map; you can also drop a file onto the map. Undo brings back the map you replaced, until you reload the page.

The YAML does not record which side of the centre a branch is on, so an opened map shares its branches between left and right.

The current map is also kept in this browser between visits, but not on other browsers or devices, so use Save to keep a copy.
