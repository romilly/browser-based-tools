# browser-based-tools

Small productivity tools that run entirely in your web browser. Each tool is a single HTML file: there's nothing to install, no server, and your files never leave your computer.

- **SQLite Browser** — open a SQLite database, browse its tables and run SQL against it.
  [More about the SQLite Browser](https://romilly.github.io/browser-based-tools/sqlite-browser/)
- **CRUDulator** — design a database of linked tables and get a data-entry application for it.
  [More about CRUDulator](https://romilly.github.io/browser-based-tools/crudulator/)
- **Mind Map Editor** — build Freeplane-style mind maps with notes, maths, images, icons and connectors.
  [More about the Mind Map Editor](https://romilly.github.io/browser-based-tools/mindmap-editor/)
- **Diagram Editor** — draw diagrams of nodes joined at named ports, saved as YAML for programs to read.
  [More about the Diagram Editor](https://romilly.github.io/browser-based-tools/diagram-editor/)

To run the tests or record the demo videos, see [CONTRIBUTING.md](CONTRIBUTING.md).
