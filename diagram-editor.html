How to use the editor

What a diagram is

Nodes with named input and output ports, and edges that each run from an output port to an input port. Every node has an id, shown in the panel, which stays the same when you change its label; programs that read the saved file refer to nodes by it.

Mouse and touch

Click or tap
Select a node or an edge.
Drag a node
Move it. Its edges follow.
Drag a port
Move it along the node's border, or round to another side.
Selected edge
Drag either of its two handles to bend it. Automatic curve in the panel straightens it out again.
Connect
Then drag from one node to another, or tap one and then the other, to draw an edge between them. The edge leaves the first node from an output port where you started and enters the second at an input port where you finished; starting or finishing on an existing port uses it. Connect stays on until you press it again or Esc, and while it is on, dragging never moves a node.
Double-click or tap
Edit a node's label.
Drag empty space
Move around the diagram.
Pinch, or Ctrl + wheel
Zoom in and out.
Type and shape
Choose a node's type in the panel, or Other… to type any name. Each type the editor knows has its own shape; a node of any other type is a rectangle with its type above the label, «like this». Shape sets the shape of every node of the selected node's type.
Hover a port
Shows its name and data type. Rename a port or give it a data type in the panel; × deletes it, with its edges.
Delete an edge
Also deletes the ports it leaves unused that the editor named (in1, out2 …) and that have no data type.

Keyboard

N
Add a node.
C
Turn Connect on or off.
F2
Edit the selected node's label. Enter finishes, Shift+Enter starts a new line, Esc cancels.
Delete
Delete the selected node, with its edges, or the selected edge.
Ctrl+Z / Ctrl+Y
Undo and redo.
+ / - / 0
Zoom in, zoom out, show the whole diagram.
Ctrl+O / Ctrl+S
Open and save.

Saving

Save downloads the diagram as a YAML file named after its title; Open reads one back, and you can also drop a file on the diagram. The format is defined by diagram-schema.json. The diagram is also kept in this browser between visits, but not shared with other browsers or devices.

When the editor comes from the mind map server on your network (mindmap_server.py), the File menu also has Open from server… and Save to server, so every device sees the same diagrams. While a diagram from the server is open, the address bar links to it (for example from a note), Ctrl+S saves it back to the server, and the browser asks before you close the tab with changes not yet saved there.

Diagrams on the server can be kept in folders. Open from server and Save to server show one folder at a time: choose a folder to look inside it, and use the path at the top to go back up. In both, each diagram has Move…, to rename it or put it in another folder, and Delete, which moves it to a .trash folder on the server. Saving a new diagram asks for its name and folder; New folder… makes one, which is kept once a diagram is in it.
