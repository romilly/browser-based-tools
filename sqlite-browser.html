    Using SQLite Browser

    Opening a database

    Click Open database file… and choose a SQLite file (usually .db, .sqlite or .sqlite3), or drag the file anywhere onto the page. The page opens with a small sample database marked Sample data so you can try it first.

    Your file is never uploaded. SQLite runs inside your browser using sql.js, and the database is held in memory.

    Browsing tables

    • The Tables panel lists every table and view.
    • Click a name to see its columns and types. The primary key is shown in the accent colour.
    • Clicking a table also runs SELECT * … LIMIT 100 so you can see its contents.

    Running queries

    • Type any SQL in the Query box and click Run query, or press Ctrl+Enter (⌘+Enter on a Mac).
    • Several statements separated by semicolons are run in order. Each one that returns rows gets its own result grid.
    • Errors from SQLite are shown in red above the results.
    • Results show the first 5,000 rows. Add a LIMIT if you need fewer.
    • NULL values appear in grey italics. BLOB columns show their size rather than their contents.

    Changing and saving data

    You can run INSERT, UPDATE, DELETE, CREATE TABLE and other statements. They change the in-memory copy only; the file on your disk is untouched.

    To keep your changes, click Download database. Your browser saves it like any other download, using the name of the file you opened. If your browser is set to ask where to save files, you can choose the name and folder.

    When the page is opened inside Claude, the database is saved inside a .zip file, because Claude doesn't allow .db downloads directly.

    Requirements

    The page loads sql.js and JSZip from cdnjs, so it needs an internet connection when it first opens.
