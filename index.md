# Browser-based tools

Small productivity tools that run entirely in your web browser. Each tool is a single web page: there's nothing to install, no server, and your files never leave your computer. They work on a desktop, a tablet or a phone.

## [SQLite Browser](sqlite-browser/)

Open a SQLite database, browse its tables and run SQL against it.

## [CRUDulator](crudulator/)

Design a database of linked tables and get a data-entry application for it: list, search, add, edit and delete records, and import and export CSV.

## [Mind Map Editor](mindmap-editor/)

Build mind maps in the style of Freeplane, with notes in Markdown, maths, images, icons, web links and connectors.

## [Diagram Editor](diagram-editor/)

Draw diagrams of nodes joined at named ports, such as flowcharts and data-flow pipelines, saved as YAML for programs to read.
