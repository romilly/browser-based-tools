# ❓ ℕ natural numbers

$\mathbb{N} = \{1, 2, 3, \dots\}$

Authors disagree about whether 0 is a natural number. Those who include it write $\mathbb{N} = \{0, 1, 2, \dots\}$ and $\mathbb{N}^+$ for the positive natural numbers. It rarely matters, but when it does, say which you mean.
