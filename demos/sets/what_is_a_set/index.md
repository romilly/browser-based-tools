# What is a set?

A **set** is a collection of objects, called its *elements*. Order doesn't matter, and each element counts only once.

We write $x \in X$ when $x$ is an element of $X$.

For example, if $a = 2$ and $b = c = 1$, then $\{a, b, c\} = \{1, 2\}$ has just two elements.
